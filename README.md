# Meeting.AI Homebrew Tap

Homebrew formulas for Meeting.AI tools.

## Install memo

```bash
brew install meeting-ai/tap/memo
```

Then let your AI agents know about memo:

```bash
memo install-skill-md
```

To upgrade:

```bash
brew upgrade memo
```

Source and releases: [meeting-ai/memo-cli](https://github.com/meeting-ai/memo-cli).
